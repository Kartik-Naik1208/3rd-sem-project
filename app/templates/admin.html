Application Factory Architecture

IngredientIQ is structured cleanly using Flask's application factory design pattern:

• app/__init__.py: create_app() factory
• app/routes/: Modular Blueprints (main, auth)
• app/models/: SQLAlchemy DB Models (User, Ingredient, ScanRecord)
• app/services/: OCR, RapidFuzz Analyzer, ReportLab PDF
• app/templates/: Jinja2 + Bootstrap 5 responsive templates
• app/static/: CSS, JS & secure uploads
• data/: Seed ingredient datasets
• tests/: Automated Pytest test suite
